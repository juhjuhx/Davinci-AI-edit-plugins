# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Smart A-Roll runs entirely **offline** — no data leaves your machine. However,
if you discover a security vulnerability in the code itself, please report it
privately by opening a GitHub Security Advisory at:

https://github.com/juhjuhx/Davinci-AI-edit-plugins/security/advisories

Do **not** report security issues in public issues or discussions.

## What to Include

- A clear description of the vulnerability
- Steps to reproduce (if applicable)
- Affected version(s)
- Potential impact

## Response Time

We aim to acknowledge reports within 48 hours and provide a fix timeline
within 5 business days.
