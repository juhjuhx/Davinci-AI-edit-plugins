# 04_標準作業流程 (SOP)

為了達到最佳的口播剪輯效率，請遵循以下標準作業流程 (Standard Operating Procedure)：

```
[啟動軟體] ──> [載入視訊與分析] ──> [網頁端預覽與微調] ──> [套用至 DaVinci] 或 [直接 FFmpeg 匯出]
```

---

## 階段一：啟動軟體服務 (Startup)
1.  **啟動服務**：
    進入專案根目錄（或解壓後的執行檔目錄），雙擊執行 `launch.bat`。
    *   *背景運作機制*：啟動腳本會自動檢測並強制關閉之前可能殘留在 `8888` 連接埠的舊後端處理程序，檢查依賴，隨後啟動 Flask Web 伺服器。
2.  **開啟網頁介面**：
    服務啟動後，瀏覽器會自動彈出並打開 `http://127.0.0.1:8888` 網頁。

---

## 階段二：載入視訊與進行 AI 分析 (Analysis)
1.  **選擇影片檔案**：
    *   在網頁頂部點擊「瀏覽影片」按鈕，在彈出的視窗中選取需要剪輯的口播影片（如 `.mp4`, `.mov`, `.mkv` 格式）。
2.  **配置分析參數（選用，點擊右上角設定）**：
    *   **語音模型**：一般電腦推薦使用 `base` 或 `small` 模型平衡速度與精準度；配備有 NVIDIA 獨立顯卡（VRAM > 6GB）的電腦，強烈建議選擇預設的 `large-v3` 模型以獲得最精準的識別效果。
    *   **LLM 二次確認**：若要開啟此功能，請先確保已下載 `qwen2.5-0.5b-instruct-q4_k_m.gguf` 模型並放在專案目錄下，並在設定中啟用此開關。
    *   **停頓間距 (Pause Gap)**：預設為 `2.0` 秒。若希望影片節奏更緊湊，可調低至 `1.0` 秒或 `1.5` 秒。
3.  **開始 AI 分析**：
    *   點擊「🚀 開始 AI 分析」。
    *   網頁上會實時透過進度條顯示當前步驟：`讀取視訊資訊` -> `提取音訊` -> `Whisper 轉錄中` -> `計算音訊波形` -> `LLM 二次確認中` -> `分析完成`。
    *   分析日誌框會同步滾動，顯示發現了多少處口頭禪、停頓與 NG 標籤。

---

## 階段三：網頁端人工檢視與微調 (Timeline Review)
AI 分析完畢後，網頁會載入音訊波形圖和文字段落：

1.  **理解顏色標記**：
    *   **綠色 (Usable)**：正常說話片段，預設保留。
    *   **紅色 (Cut)**：被判定為需要剪除的片段（如 NG 片段、清喉嚨、指令等）。
    *   **橙色 (Filler)**：填充詞/贅字（如「然後」、「那個」）。
    *   **黃色 (Repeat / Hesitation)**：重複句或猶豫卡詞。
    *   **藍色 (Silence)**：長停頓或無聲音區。
2.  **使用預覽與快捷鍵**：
    *   **畫面預覽**：點擊波形 timeline 上的任意位置，右側預覽視窗會即時加載對應的視訊畫面（1/4 解析度 JPEG）。
    *   **手動覆寫**：滑鼠點擊任意片段，可手動將其切換為「保留（Keep）」或「剪除（Cut）」，片段的顏色會隨之改變。
    *   **快捷鍵操作指南**：
        *   `Space (空白鍵)`：播放 / 暫停。
        *   `Q`：剪切（Cut）當前播放游標**以前**的語句片段。
        *   `W`：剪切（Cut）當前播放游標**以後**的語句片段。
        *   `B`：切換為**剃刀模式 (Razor)**。在該模式下點擊波形可以將長語句從中「切開」成兩段，以便進行更細緻的局部剪除。
        *   `Alt + =` / `Alt + -`：放大 / 縮小時間軸。

---

## 階段四：套用與成果匯出 (Integration & Export)
在完成微調後，可選擇以下**三種途徑之一**來套用您的剪輯成果：

### 途徑 A：導入至 DaVinci Resolve (專業剪輯工作流 - 推薦)
當您需要對口播影片進行精緻包裝、加特效、調色時使用：
1.  **準備時間軸**：
    打開 DaVinci Resolve，建立新專案，將剛剛分析的**原始影片**拖入媒體池，並建立一個時間軸，將影片放置在**第一軌 (Video Track 1)**，且起始點對齊時間軸開頭。
2.  **執行導入腳本**：
    *   在 DaVinci 的頂部選單中，點擊 `Workspace -> Scripts -> apply_to_resolve`（或執行 `davinci_smart_aroll_v2.py`）。
3.  **開始精剪**：
    *   腳本執行完畢後，回到 DaVinci 時間軸，您會發現第一軌的影片片段已經被自動著色：被判定為**保留的片段全部變成綠色**，被判定為**剪除的片段全部變成紅色**。
    *   同時，所有剪除區間都加上了彩色 Markers 標記（內含文字備註與 AI 判定理由）。
    *   剪輯師只需對著紅色區段進行快速裁切與刪除，即可完成粗剪。

### 途徑 B：直接 FFmpeg 快速匯出 (快速出片工作流)
當您只需要迅速切掉廢話、不需要進入剪輯軟體二次包裝時使用：
1.  **選擇匯出品質**：
    *   **無損快速合併 (Stream Copy - 推薦)**：不重新編碼視訊，直接將保留片段提取並拼接。速度極快（幾秒鐘即可完成），畫質 100% 無損。
    *   **H265 10bit 422 / H264**：重新進行視訊編碼，會調用 NVIDIA NVENC GPU 硬體加速。
2.  **音訊增強開關**：
    *   可選擇是否開啟「響度標準化」與「音訊去噪」，讓聲音聽起來更清晰飽滿。
3.  **一鍵匯出**：
    *   點擊「匯出剪輯影片」。FFmpeg 會在後台以高速完成剪輯，生成的新視訊會自動儲存於原始影片的同目錄下，檔名加上 `_edit` 後綴。

### 途徑 C：匯出中介格式與字幕 (Metadata Export)
*   工具支援一鍵匯出多種格式的剪輯資料：
    *   **EDL 剪輯表**：可用於導入 Premiere、Resolve 或 Final Cut Pro 的通用時間軸剪輯表。
    *   **SRT 字幕檔**：自動將 Whisper 轉錄的文字轉換為時間軸字幕檔。
    *   **CSV / JSON 數據**：匯出完整的文字與時間戳記對應數據，供其他程式調用。
