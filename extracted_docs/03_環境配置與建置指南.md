# 03_環境配置與建置指南

## 1. 系統環境需求 (System Prerequisites)
*   **作業系統**：Windows 10/11 (核心支援，亦可在 macOS/Linux 運行但需修改 bat 腳本)
*   **Python 版本**：Python 3.10+ (推薦使用 Anaconda/Miniconda 建立獨立環境，或使用系統 Python)
*   **FFmpeg 工具**：
    *   運作必須包含 `ffmpeg.exe` 和 `ffprobe.exe`。
    *   必須下載並將其所在目錄（例如 `C:\ffmpeg\bin`）加入到 Windows 的系統 `PATH` 環境變數中；或者，將其路徑寫入專案的 `config.json` 檔案中。

---

## 2. 原始碼建置與依賴安裝 (Setup from Source)

### 步驟 2.1：複製專案
```bash
git clone https://github.com/YOUR_USERNAME/SmartARoll.git
cd SmartARoll
```

### 步驟 2.2：自動安裝基本依賴
雙擊專案目錄下的 `install.bat`，或手動在終端機中執行：
```bash
pip install -r requirements.txt
```
該步驟會自動安裝 Flask 後端、faster-whisper 語音轉錄、librosa 音訊分析、pydub 及 numpy 等核心套件。

### 步驟 2.3：安裝對應 GPU 加速管道的 LLM 推理庫 (llama-cpp-python)
如需啟用本地大語言模型二次驗證，需要依據您的顯示卡硬體，安裝對應編譯版本的 `llama-cpp-python`：

*   **通用 CPU 運作（無 GPU 加速）**：
    ```bash
    pip install llama-cpp-python
    ```
*   **NVIDIA 顯示卡 (CUDA 加速 - 最推薦)**：
    ```bash
    pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu
    ```
*   **AMD / Intel Arc 顯示卡 (Vulkan 加速)**：
    ```bash
    pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/vulkan
    ```
*   **Intel 整合/獨立顯示卡 (SYCL 加速)**：
    ```bash
    pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/sycl
    ```
*   **Apple Silicon (Metal 加速)**：
    ```bash
    CMAKE_ARGS="-DGGML_METAL=on" pip install llama-cpp-python
    ```

## 3. 自行打包與釋出 (.exe & .zip Packaging)
專案內建 `build.bat`，可一鍵將 Python 原始碼封裝為 Windows 獨立執行檔軟體包：

### 步驟 3.1：準備打包
1.  確保已安裝 `pyinstaller` (打包腳本會自動檢查並安裝)。
2.  確定系統中能找到 `ffmpeg.exe`（打包腳本會自動檢測 `C:\ffmpeg` 或系統 `PATH`，若找不到會提示用戶輸入路徑以便將 FFmpeg 一併打包進去）。

### 步驟 3.2：執行打包
雙擊執行 `build.bat`。打包流程如下：
1.  呼叫 PyInstaller 進行編譯，指令為：
    ```bash
    pyinstaller --name=SmartARoll --onefile --noconfirm --clean --add-data="core;core" --add-data="workers;workers" --add-data="ui;ui" --add-data="config.json;." api\app.py
    ```
    這會將所有 Python 後端代碼、WebUI 前端靜態頁面、設定檔等合併打包為單一的 `SmartARoll.exe`。
2.  **建立綠色免安裝軟體夾**：
    在 `dist/SmartARoll_v4.0` 下建立軟體發行結構：
    *   複製 `SmartARoll.exe`
    *   複製 `config.json`
    *   複製 `apply_to_resolve.py` (DaVinci 腳本)
    *   建立空白 `results/` 與 `logs/` 目錄。
    *   若有檢測到 FFmpeg，會自動建立 `ffmpeg/` 資料夾並將其複製進去。
    *   自動寫入一個免安裝版的 `launch.bat` 一鍵啟動指令。
3.  **壓縮打包為 .zip**：
    使用 PowerShell 指令將該資料夾打包：
    ```powershell
    Compress-Archive -Path 'dist\SmartARoll_v4.0\*' -DestinationPath 'dist\SmartARoll_v4.0.zip' -Force
    ```
4.  **建立安裝程式**（選用）：若系統已安裝 NSIS，會自動執行編譯產生安裝引導程式 `dist/SmartARoll_v4.0_Setup.exe`。

## 4. DaVinci Resolve 插件部署 (Resolve Integration Setup)
若要將 AI 標記結果直接套用到 DaVinci 時間軸上：

*   **自動/手動拷貝**：
    將專案目錄（或打包後目錄）下的 `apply_to_resolve.py`（以及優化版圖形介面 `davinci_smart_aroll_v2.py`）複製到 DaVinci Resolve 的腳本公用目錄中：
    *   **Windows (全域)**: `C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility`
    *   **macOS (全域)**: `/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility`
    *   **Linux (全域)**: `/opt/resolve/Fusion/Scripts/Utility`
*   **權限與設定啟用**：
    在 DaVinci Resolve 中，進入 `Preferences -> System -> Control Panels / Scripting`，確保 **External scripting using** 設定為 **Local**，以便允許外部 Python 腳本調用 Resolve API。
